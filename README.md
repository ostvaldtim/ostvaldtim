## Prompt engineering

I design prompts and model workflows for more than chat-style interactions. Typical tasks include:

- **Coding:** codebase reading, implementation, refactoring, debugging and verification workflows.
- **Video & image generation:** detailed prompts that push models to inspect composition, movement, continuity, style and constraints instead of producing a generic result.
- **System prompts:** persona design, structured outputs, guardrails, tool/context instructions and multi-step behaviour.
- **Research:** turning large or ambiguous tasks into smaller verifiable steps and controlling the format and evidence expected from the model.
